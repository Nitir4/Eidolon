# Transportation balancing and allocation iterations

On the working `future-scope` branch, all three initial heuristics (North-west Corner, Least Cost and Vogel) accept unequal supply/demand totals. A zero-cost dummy destination absorbs unused supply, or a zero-cost dummy source accounts for unmet demand. The solver retains the original document and solves a labelled working copy. Zero dummy cost means no explicit storage or shortage penalty.

Use **Solve Problem → Iterations → [method]**. Inside the method screen, **Initial allocation steps** provides Previous/Next/All allocation controls. The grid shows cumulative basic shipments, residual quantities after the selected allocation and Vogel penalties used before it. Inactive lines have no penalty; a singleton has penalty zero. Ties retain input order (sources before destinations for Vogel). Costs/profits and the min(supply,demand) calculation appear with each selected allocation. For maximization, Least Cost selects highest profit and Vogel computes penalties on negated profits.

The **MODI iterations** tab retains Next/All iteration controls, multipliers and manual loop feedback. Its explanation identifies positive/basic shipment counts, degeneracy, entering/leaving cells, theta and the signed loop. A basic zero is a member of the connected m+n−1-cell basis and carries no physical flow. A repeated basis switches to Bland's ordered pivot rule; iteration safeguards still apply. Final summaries and printed MODI tables include automatic dummies.
