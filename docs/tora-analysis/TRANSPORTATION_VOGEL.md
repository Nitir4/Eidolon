## Allocation and improvement contract

For every active source row and destination column with at least two active
cells, subtract the smallest cost from the second smallest, counting equal
costs separately. Select the largest penalty; exact ties retain the first
source row, then subsequent source rows, then destination columns in input
order. Within the selected line choose the smallest-cost cell, keeping its first
input-order occurrence on ties. Case14 rejects cheapest-cell secondary penalty
ties; probe19 distinguishes row-first from column-first priority.

Allocate the smaller remaining supply/demand. Remove exactly one exhausted
source while more than one source remains; otherwise remove the exhausted
destination. Equal exhaustion preserves the other line and a subsequent basic
zero. Recompute penalties after each allocation. Negative and zero costs and
zero quantities occur in captured inputs. A singleton line uses zero penalty in
the clone: its internal TORA penalty is unobservable here, but remaining cells
are forced and tested policies produce the same basis. Do not claim TORA's
internal sentinel has been identified.

The shared MODI contract uses u1=0, basic u+v=cost, reduced u+v−cost; largest
positive reduced cost enters, minimum minus-position shipment leaves, with
source/destination-order ties. No positive reduced cost terminates. Explicit
basic zero shipments and nonbasic blank cells remain distinct.

## Native output and navigation

The shared native table shows each tableau's cost/shipment/reduced-cost rows,
u/v, supply/demand, ObjVal and Iter label. Next/All append iterations. An initially
optimal start shows `Optimal Tableau` / `Iteration 1 is optimal`; advancement
to the final tableau shows `Iteration N is optimal`. Terminal controls disable.
Qt suppresses QMessageBox titles on macOS by its documented native behavior;
message, icon and button remain checked. Choosing another method replaces the
trace only on success; errors preserve the prior model, method and trace.
Cached output pages refresh their heading and table. Fonts, scrolling and
layouts share the native HiDPI framework.
